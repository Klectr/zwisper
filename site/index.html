Why it exists

Tired of being upsold
for talking to my computer.

I kept trying dictation and transcription apps. I'd have to pick one or the other, or find one that did both but hid half of it behind a paywall. They start you free, get you used to it, then lock you out until you subscribe to Pro.

So I built my own, and made it free for everybody. Stop renting your voice. Take Zwisper and make it your own.

Get Zwisper

Download the app

Grab the latest .dmg from GitHub Releases and drag Zwisper into Applications. Models download the first time they're needed.

Latest release

Zwisper isn't notarized by Apple, so macOS stops it the first time. Open System Settings → Privacy & Security and click Open Anyway.

Build from source

You need Rust and the Xcode Command Line Tools. One command builds the app and opens the installer.

git clone https://github.com/Klectr/zwispercd zwisper && cargo app

It's MIT licensed: fork it, change it, ship your own.
